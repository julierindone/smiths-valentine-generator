# Not Like Any Other Love: A Smiths & Morrissey Valentine Generator

A valentine generator using images and lyrics of The Smiths and Morrissey. I used the css from my other Smiths-related project, [The World Won't Lipsum - a lorem ipsum generator](https://lorem-smithsum.netlify.app/), as a starting point.

By next February 2027, I plan to add:
1. A filter so users can choose between all Smiths, all Moz, or a mix.
2. A button for easy copying of the generated valentine.
3. More images and more lyrics. The possibilities are endless.

Create your own: [https://valentines-from-the-smiths.netlify.app/](https://valentines-from-the-smiths.netlify.app/)
